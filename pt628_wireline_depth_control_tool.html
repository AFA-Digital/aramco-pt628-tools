PT 628 - Borehole Imaging: Wireline Depth Control

Module 3 - increase cable stretch to see the logged depth drift from the tool's true position, then correlate to a formation marker to correct it.

Interactive tool showing a wellbore with a wireline tool run on cable from surface. A cable stretch slider offsets the surface-measured depth from the tool's true depth, opening a gap against a fixed formation marker. A correlate button snaps the measured depth back into alignment, demonstrating why depth correction against reference logs is necessary.
